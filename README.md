# Java String Methods

##  About the Project

This repository contains five Java programs demonstrating commonly used String methods in Java.

Each program demonstrates a different String operation, including accessing a character, finding a substring position, calculating string length, and converting strings into uppercase and lowercase.

This repository was created as part of my Java programming practice to understand and explore Java String handling methods.

##  Programs Included

### 1. charAt() – StringcharAt.java
- Accesses a character at a specified index in a string.
- Example: `malleshwari`
- Index: `7`
- Output: `a`

### 2. indexOf() – Stringindex.java
- Finds the starting index of a specified substring.
- Example: `vayasi malleshwari`
- Searches for: `malleshwari`
- Output: `6`

### 3. length() – Stringlen.java
- Returns the total number of characters in a string.
- Example: `malleshwari`
- Output: `11`

### 4. toLowerCase() – Stringlo.java
- Converts all uppercase characters into lowercase.
- Example: `MALLESHWARI`
- Output: `malleshwari`

### 5. toUpperCase() – Stringup.java
- Converts all lowercase characters into uppercase.
- Example: `malli`
- Output: `MALLI`

##  How to Run

**Prerequisite:** Java Development Kit (JDK) installed.

Each program is written in a separate Java class.

Compile and run each program individually:

**1. StringcharAt**
```bash
javac StringcharAt.java
java StringcharAt
```

**2. Stringindex**
```bash
javac Stringindex.java
java Stringindex
```

**3. Stringlen**
```bash
javac Stringlen.java
java Stringlen
```

**4. Stringlo**
```bash
javac Stringlo.java
java Stringlo
```

**5. Stringup**
```bash
javac Stringup.java
java Stringup
```
